# UL要素カウンター (Chrome Extension)

ページ内の `ul` 要素を可視化し、クリックすることで子要素の数を手軽にカウントできる開発用ブラウザ拡張機能（Manifest V3）です。

## 使い方

1. このリポジトリをクローンまたはダウンロードします。
2. Chromeの拡張機能ページ (`chrome://extensions/`) を開きます。
3. 右上の **「デベロッパー モード」** をONにします。
4. **「パッケージ化されていない拡張機能を読み込む」** から本フォルダを選択します。
5. 任意のページで拡張機能アイコンをクリックし、「ULを選択モードを開始」を押してください。
